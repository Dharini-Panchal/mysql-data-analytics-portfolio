# MySQL Retail Analytics Project — Interview Walkthrough

## 60-Second Introduction

I built an independent MySQL retail analytics project to practise solving business problems with SQL.

I organized the analysis into data profiling, data quality checks, cleaning validation, KPI analysis, customer behaviour, sales performance, product and inventory analysis, and customer satisfaction.

I used SQL techniques such as joins, aggregations, subqueries, CTEs, and window functions to investigate business questions. I also documented the metrics, assumptions, limitations, and recommendations so the analysis can be reviewed.

The project helped me practise moving from raw operational data to structured analysis and business-oriented reporting.

## If Asked About a Challenge

One important part of the project was distinguishing unusual data from confirmed errors. For example, a missing value, a zero order total, or low inventory needs context before deciding what action to take.

I documented validation rules and used SQL checks to make the analysis more transparent.

## If Asked About Business Value

The queries are designed to help investigate customer revenue contribution, product performance, potential inventory risks, and customer ratings.

I would verify the actual results and business context before recommending an operational change.

## If Asked About Experience

This is an independent portfolio project using a simulated retail dataset. It demonstrates my SQL and analytical skills; it is not professional employment experience or a project delivered for an employer.
